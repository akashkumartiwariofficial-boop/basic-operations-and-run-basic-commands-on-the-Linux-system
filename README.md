# Basic Operations and Linux Commands

## 🧠 Objective
Perform basic operations and run essential Linux commands as part of the TuteDude Cybersecurity course.

## 🧩 Description
This repository contains tasks and exercises for learning fundamental Linux commands and performing basic operations on the system.  
It includes screenshots, documentation, and answers as per the submission guidelines provided in the course.

## ⚙️ Steps
1. Open the TryHackMe Room and connect to the target machine via SSH.  
2. Execute the required Linux commands as instructed in the course video.  
3. Capture screenshots of the outputs and upload them here.
